## 2. Locked Format Decisions (`3:0` Unanimous)

- **Single A4 (`249 PLN`)**: Uses `1x3` (`3` strips, `120x56.67 mm`) inside one `21x29.7 cm` white passe-partout frame. Ships via Paczkomat A/B.
- **Triptych (`599-649 PLN`, Execution A)**: Uses `3x(1x3)` (`9` strips, `120x56.67 mm`) across three separate Heavy A4 frames.
  - Reuses `100%` of Single A4 frame and foam inventory with zero vertical resin seams across the skyline.
  - Fits Paczkomat B/C and unlocks post-purchase upsells for existing Single A4 buyers.
  - Flagship route: **Warsaw West-East Panorama** (`Centrum -> Powisle -> Wisla + Mosty -> PGE Narodowy`).
- **Quartet vs. True `1:1` Square (`549-699 PLN`)**:
  - `4x(1x3)` forms a `240x340 mm` (`1:1.42`) portrait Quartet (`12` strips, `799 PLN` 4-frame set), never a square.
  - `3x4` (`120x90 mm` strips) exceeds the `87.05 mm` Mono 4 LCD bed and cannot print.
  - **True `1:1` Square (`240x240 mm`)** locks **`2x4` = `8` strips (`120x60 mm`)** inside a `33-35 cm` frame.
  - This cuts resin and print time by `33%` versus `12` strips while fitting Paczkomat B cleanly.
- **Flagship `50 x 70 cm` (`1,499-1,699 PLN`, MTO Courier)**:
  - Locks **`3x9` (`9 x (1x3)` = `27` strips of `120.0 x 56.67 mm`)** forming a `360 x 510 mm` window.
  - Odd `3 x 9` keeps the center hero tile (`R5C2`) completely seamless and shares `100%` of A4 strip tooling.
  - Bond all `27` strips onto rigid `3 mm` matte-black HDF or Dibond backing to support `~1.0-1.3 L` resin weight.
